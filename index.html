GitHub Gist 备份教程

第一次使用时，按下面步骤创建一个只拥有 gist 权限的 GitHub Token。

  1. 进入网页 github.com
  2. 注册登录
  3. 右上角点击自己头像
  4. Settings
  5. 【电脑版】看左边列表，拉到最下面，点 Developer settings / 【手机版】点击 Public profile 上方的 Menu，拉到最下面，点 Developer settings
  6. 点 Personal access tokens
  7. Tokens(classic)
  8. 点击 Generate new token
  9. 选择 Generate new token(classic)
  10. 填写三个地方：【① Note - 为这个 token 起名】【② Expiration - 选 No expiration】【③ 一堆复选框中，找到一个 gist - Create gist 的复选框，勾起来】
  11. 拉到最下面，选择 Generate token
  12. 复制 ghp 带头的 token（请妥善保存，它只会展示一次）
  13. 粘贴进 TeleWindy
  14. 直接点“上传云备份”，输入加密密码，即可备份

和风天气配置教程

和风天气官网：https://dev.qweather.com/

  1. 打开上面的和风天气开发服务网址，注册并登录。
  2. 进入控制台，在项目管理中创建一个项目。
  3. 给项目创建“API KEY”类型的凭据，并复制生成的 API Key。
  4. 进入控制台-设置，找到自己的专属 API Host。
  5. 把 API Host 和 API Key 分别粘贴到 TeleWindy 的对应输入框。
  6. 填写城市，点击“搜索地点”并选择正确地点。
  7. 点击“测试天气”；页面显示“来源：和风天气”就是配置成功。
